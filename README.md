# About the Project

A web application that enables users to engage in an interactive voice conversation with AI, designed to improve their English speaking skills and grammar through personalized feedback. The app converts the user’s recorded speech to text and sends it to GPT-3 to generate a response, which is delivered to the user in a text-to-speech format.

![](https://personal-website-5bhbo0ak7-ofeksror.vercel.app/_next/image?url=%2FenglishCoachDemo.png&w=2048&q=75)

The messages you see here are a transcript of the conversation.
To start a conversation, the user would press on the record button and record a message to his AI-powered teacher.
A response would be generated by the AI and delievered to the user in text-to-speech.
<br>
Notice that messages from the AI have two parts:
1. A response to the conversation with the user. The AI is prompted to be friendly and engaging
2. A personalized feedback on the user's last message - mentioning mistakes and corrections.
<br>
An example of personalized feedback:
Assuming the user says something like "I played basketball tomorrow" - confusing the past and the future, the AI's response would mention that mistake and give him a correct way to say that sentence - i.e. "I played basketball yesterday"
